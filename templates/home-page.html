Monthly Challenges

Twelve months, twelve challenges. Every month of the year has one small habit attached to it — pick a month and see what you signed up for.

What this project shows

  • One dynamic route for all twelve months. A single view handles every month instead of twelve near-identical views.
  • Two ways to reach a month. /challenges/march/ renders the page; /challenges/3/ redirects to it, so numbers and names both work.
  • Template inheritance. Every page extends main-layout.html and fills in the title and content blocks, so the shell and styling live in exactly one place.
  • A reusable partial. The navigation bar above is main-nav.html, included by the layout rather than copied into each page.
  • Named URLs. Links are built with {% verbatim %}{% url "monthly-challenge" month %}{% endverbatim %}, so the URL pattern can change without hunting down hardcoded paths.
